JALSHA TV — INSTALLABLE WEB APP PACKAGE

This package is a Progressive Web App (PWA), not a signed native APK. It can be installed on Android from Chrome and launches full-screen with its own home-screen icon.

IMPORTANT REQUIREMENTS
- It must be hosted on an HTTPS website for installation and offline caching.
- The app opens the JioHotstar link saved for each show. Hotstar may open a show page rather than automatically selecting the newest episode. Update the saved episode link when needed.
- This app does not bypass Hotstar login, subscription, ads, or playback restrictions.
- Show data is saved locally in the browser on this tablet. Use Export backup before clearing browser data.

FILES
- index.html: app interface and show manager
- manifest.webmanifest: install metadata
- sw.js: app-shell offline cache
- icons/icon.svg: app icon

INSTALL AFTER HOSTING
1. Open the hosted HTTPS address in Chrome on the Realme Pad.
2. Open Chrome menu (three dots).
3. Choose Install app or Add to Home screen (wording varies).
4. Confirm. Launch Jalsha TV from the new home-screen icon.

FREE HOSTING OPTION
You can host these files using GitHub Pages. Create a public repository, upload the contents of this folder to its root, enable Pages from Settings > Pages, then open the generated HTTPS URL on the tablet.

The serial list starts with Ashirbad, Tilottama, Kumkum, Pratigga, Parashuram, Professor Bidya Banerjee, and Gangaa. Add the Hotstar show/episode URLs and poster image URLs through the gear button.
